# React Learning Todo App

Đây là dự án cá nhân được xây dựng trong quá trình học React. Dự án bắt đầu từ một Todo App đơn giản và được mở rộng dần để thực hành các kiến thức từ cơ bản đến nâng cao trong React.

## Mục tiêu

- Làm quen với React và JSX
- Tìm hiểu cách xây dựng và tái sử dụng component
- Quản lý state và dữ liệu trong ứng dụng
- Thực hành xử lý form, sự kiện và danh sách
- Kết nối ứng dụng với API
- Tìm hiểu định tuyến và tổ chức cấu trúc project
- Theo dõi tiến độ học React và Frontend Development

## Công nghệ sử dụng

- React 19
- Vite
- JavaScript
- JSX
- React Hooks
- React Router
- Fetch API
- Axios
- CSS
- ESLint

## Những nội dung đã thực hành

- JSX và Components
- Props và Event Handling
- `useState`
- Controlled Input
- Quản lý mảng và object trong state
- Thêm, sửa, xóa Todo
- Đánh dấu Todo đã hoàn thành
- Tách component như `TodoForm`, `TodoList`, `TodoItem`
- Lọc Todo theo trạng thái
- Lưu dữ liệu với `localStorage`
- Custom Hook
- `useEffect`
- `useRef`
- `useMemo`
- `useCallback`
- `React.memo`
- Context API
- Loading State và Error Handling
- Fetch API và Axios
- CRUD với API
- React Router và nested routes

## Tính năng hiện tại

- Hiển thị danh sách công việc học tập
- Theo dõi các nội dung đã hoàn thành và chưa hoàn thành
- Quản lý Todo
- Phân loại Todo theo trạng thái:
  - Tất cả
  - Đang thực hiện
  - Đã hoàn thành
- Xem chi tiết từng Todo
- Điều hướng giữa nhiều trang trong ứng dụng
- Làm việc với dữ liệu từ API

## Cài đặt và chạy dự án

```bash
npm install
npm run dev
```

Sau đó mở đường dẫn được hiển thị trong terminal để truy cập ứng dụng.

## Các lệnh khác

```bash
npm run build
npm run lint
npm run preview
```
